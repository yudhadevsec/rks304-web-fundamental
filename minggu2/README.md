# Tugas Web Minggu 2
Admin Template E-commerce murni HTML & Tailwind CSS (CDN).

## File
- `index.html` : Halaman login
- `template.html` : Starter template
- `dashboard.html` : Dasbor & stat card
- `products.html` : Daftar produk
- `add-produk.html` : Form tambah
- `edit-produk.html` : Form edit (auto-fill)
- `users.html` & `settings.html` : Halaman pelengkap menu

## Cara Pakai
Buka `index.html` di browser (wajib terkoneksi internet untuk me-load Tailwind CSS).
